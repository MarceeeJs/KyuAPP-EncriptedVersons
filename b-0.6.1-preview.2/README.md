# KyuApp b-0.6.1-preview.2

Descargá `KyuApp-Setup.exe` desde [Releases](https://github.com/MarceeeJs/KyuAPP-EncriptedVersons/releases/tag/b-0.6.1-preview.2). Windows x64; requiere Discord y rol Kyu para jugar.

El instalador descarga el paquete .kyu, verifica SHA-256, descifra e instala por usuario. El paquete grande se adjunta a Releases y se excluye de Git.

Cifrado AES-256-CBC para el paquete de distribución; integridad mediante hash fijado dentro del instalador. El instalador incorpora lo necesario para descifrar. Los archivos instalados son recuperables: no es protección anticrack. EXE sin firma Authenticode.

Preview: consultar release-manifest.json para los cambios de esta compilación. No incluye todavía toda la lista de beta 0.6.1.
